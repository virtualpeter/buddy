Buddy

Jamf Pro automation CLI. This package installs:

  • Buddy.app in /Applications
  • /usr/local/bin/buddy as a symlink to the CLI helper inside the app (Contents/Helpers/buddy)

Keep that path as a symlink rather than replacing it with a copied binary.

After install, open Terminal:

  • buddy policy list — any Jamf command, if you are already set up
  • buddy setup / buddy cred add — first-run chooser (instance, Platform, quickstart file, or MDM)
  • buddy setup secrets — if this Mac already has an org managed plist
  • buddy setup import ./quickstart.yaml — load a secrets-free identity YAML or ACS plist
  • buddy setup export ./quickstart.yaml — write that YAML from a working install
