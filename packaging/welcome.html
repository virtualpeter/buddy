Buddy

Jamf Pro automation CLI. This package installs:

  • Buddy.app in /Applications
  • /usr/local/bin/buddy as a symlink to the CLI helper inside the app (Contents/Helpers/buddy)

Keep that path as a symlink rather than replacing it with a copied binary.

After install, open Buddy.app and add a Jamf workplace in Agent Settings (⇧⌘,). The CLI at /usr/local/bin/buddy uses that Agent. Without the Agent:

  • buddy policy list — any Jamf command once a workplace exists
  • buddy setup / buddy cred add — CLI chooser (instance, Platform, quickstart file, or MDM)
  • buddy setup secrets — if this Mac already has an org managed plist
